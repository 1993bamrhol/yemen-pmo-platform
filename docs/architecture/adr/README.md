## حالات ADR

- `Proposed`: ينتظر قرار المراجعة.
- `Accepted`: معتمد للتنفيذ.
- `Superseded`: استُبدل بقرار أحدث.
- `Deprecated`: لم يعد مناسبًا، مع بقاء أثره التاريخي.
